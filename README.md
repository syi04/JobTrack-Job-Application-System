# JobTrack - Job Application Management System

## About the Project

JobTrack is a web-based job application management system developed for the IMS566 Individual Project.

The system is designed to help users keep track of their job applications, application status, interviews, and company information in one place.

## Main Features
- User login and authentication
- Job application management
- Add, edit and delete applications
- Search and filter applications
- Company information management
- Dashboard with application summary
- Application status charts
- Responsive interface
- Browser data storage

## Data Storage

The system uses browser storage to store data:

- **localStorage** – stores job application and company data.
- **sessionStorage** – manages the user's login session.

> Data stored using browser storage is only available on the browser and device where it was saved.
